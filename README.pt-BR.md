# Issues do Vectora

Entrada pública para bugs, pedidos de funcionalidade, feedback de UX e melhorias de documentação do Vectora.

[🇺🇸 English](README.md) · [🇧🇷 Português](README.pt-BR.md) · [🇲🇽 Español](README.es-MX.md)

## Como funciona

- Issues podem ser abertas aqui ou pela página de issues da Vectora Company.
- A Company sincroniza títulos, descrições, comentários, labels, responsáveis e estado pela API e pelos webhooks do GitHub.
- O CodeRabbitAI pode enriquecer novas issues e gerar um plano de implementação com `@coderabbitai plan`.
- Uma solicitação aprovada recebe a label `approved-for-core` e pode ser promovida ao repositório principal `vectora-ltda/vectora` por um fluxo autenticado.
- A promoção preserva links entre a solicitação pública e a issue do core e evita duplicações.

## Como abrir uma issue

Pesquise as issues existentes antes de abrir uma nova. Inclua comportamento atual e esperado, passos de reprodução, versão do Vectora, ambiente e evidências redigidas quando necessário. Nunca publique tokens, chaves, senhas ou dados pessoais. Para vulnerabilidades, use o canal privado de segurança.

## Estados de triagem

`needs-triage` indica que a solicitação aguarda análise. `planned` indica que existe um plano técnico. `approved-for-core` autoriza a promoção ao repositório principal. `duplicate`, `invalid` e `wontfix` encerram a triagem com um motivo explícito.
