# Contribuindo com o Vectora

Este repositório é a entrada pública de issues do Vectora. O código do produto é desenvolvido no repositório principal; aqui ficam o contexto público e a triagem.

[🇺🇸 English](CONTRIBUTING.md) · [🇧🇷 Português](CONTRIBUTING.pt-BR.md) · [🇲🇽 Español](CONTRIBUTING.es-MX.md)

Pesquise issues existentes antes de abrir uma nova. Use o template adequado, inclua contexto reproduzível e remova segredos ou dados pessoais. Use `SECURITY.md` para vulnerabilidades.

Novas solicitações começam com `needs-triage`. O CodeRabbitAI pode enriquecer a issue e gerar um plano com `@coderabbitai plan`. Mantenedores podem aplicar `approved-for-core` quando a solicitação estiver pronta para promoção ao `vectora-ltda/vectora`.

Mudanças em templates, políticas, documentação ou workflows devem usar Conventional Commits, explicar o motivo e incluir validação. Nunca faça commit de credenciais.
