# Security

Do not publish vulnerabilities, credentials, tokens, personal data, or exploitable proofs of concept in public issues.

Send security reports to [security@vectora.company](mailto:security@vectora.company) with impact, reproduction steps, and minimal evidence. Wait for confirmation before disclosure.
