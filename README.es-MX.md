# Issues de Vectora

Punto de entrada público para bugs, solicitudes de funcionalidades, comentarios de UX y mejoras de documentación de Vectora.

[🇺🇸 English](README.md) · [🇧🇷 Português](README.pt-BR.md) · [🇲🇽 Español](README.es-MX.md)

## Cómo funciona

- Las issues pueden abrirse aquí o desde la página de issues de Vectora Company.
- Company sincroniza títulos, descripciones, comentarios, etiquetas, responsables y estado mediante la API y los webhooks de GitHub.
- CodeRabbitAI puede enriquecer nuevas issues y generar un plan de implementación con `@coderabbitai plan`.
- Una solicitud aprobada recibe la etiqueta `approved-for-core` y puede promocionarse al repositorio principal `vectora-ltda/vectora` mediante un flujo autenticado.
- La promoción conserva enlaces entre la solicitud pública y la issue del core y evita duplicados.

## Cómo abrir una issue

Busca primero las issues existentes. Incluye el comportamiento actual y esperado, pasos de reproducción, versión de Vectora, entorno y evidencias redactadas cuando sea necesario. Nunca publiques tokens, claves, contraseñas ni datos personales. Para vulnerabilidades, usa el canal privado de seguridad.

## Estados de triage

`needs-triage` indica que la solicitud espera análisis. `planned` indica que existe un plan técnico. `approved-for-core` autoriza la promoción al repositorio principal. `duplicate`, `invalid` y `wontfix` cierran el triage con un motivo explícito.
