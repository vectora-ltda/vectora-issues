# Contributing to Vectora

This repository is the public intake for Vectora issues. Product code is developed in the main repository; this repository holds public context and triage.

[🇺🇸 English](CONTRIBUTING.md) · [🇧🇷 Português](CONTRIBUTING.pt-BR.md) · [🇲🇽 Español](CONTRIBUTING.es-MX.md)

Search existing issues before opening one. Use the appropriate issue template, include reproducible context, and remove secrets or personal data. Use `SECURITY.md` for vulnerabilities.

New requests start with `needs-triage`. CodeRabbitAI may enrich the issue and generate a plan with `@coderabbitai plan`. Maintainers can apply `approved-for-core` when a request is ready for promotion to `vectora-ltda/vectora`.

Changes to templates, policies, documentation, or workflows should use Conventional Commits, explain why the change is needed, and include validation. Never commit credentials.
