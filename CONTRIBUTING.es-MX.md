# Contribuir con Vectora

Este repositorio es la entrada pública de issues de Vectora. El código del producto se desarrolla en el repositorio principal; aquí viven el contexto público y el triage.

[🇺🇸 English](CONTRIBUTING.md) · [🇧🇷 Português](CONTRIBUTING.pt-BR.md) · [🇲🇽 Español](CONTRIBUTING.es-MX.md)

Busca issues existentes antes de abrir una nueva. Usa la plantilla adecuada, incluye contexto reproducible y elimina secretos o datos personales. Usa `SECURITY.md` para vulnerabilidades.

Las nuevas solicitudes empiezan con `needs-triage`. CodeRabbitAI puede enriquecer la issue y generar un plan con `@coderabbitai plan`. Los mantenedores pueden aplicar `approved-for-core` cuando la solicitud esté lista para promocionarse a `vectora-ltda/vectora`.

Los cambios en plantillas, políticas, documentación o workflows deben usar Conventional Commits, explicar el motivo e incluir validación. Nunca hagas commit de credenciales.
